# 🚀 Retro Shooter 2D

A retro-style 2D space shooter built with **Godot Engine 4**!

Take control of your spaceship, shoot incoming enemies, survive as long as possible, and see how high you can score. This project features classic arcade gameplay with retro visuals, sound effects, animations, and an unlimited-run mode.

## 🎮 Play the Game

**[⬇️ Download Retro Shooter 2D for Windows](https://github.com/NotVasuPro99/retro-shooter-2d/releases/tag/v1.0.0)**

1. Open the release page linked above.
2. Download the Windows ZIP from the release assets.
3. Extract the ZIP file.
4. Run the game executable.

*No Godot installation is required to play the exported Windows version.*

## ✨ Features

- 🚀 **Classic Arcade Gameplay** — Control your spaceship and fight incoming enemies.
- 🔫 **Shooting System** — Fire projectiles to destroy enemies.
- 👾 **Enemy System** — Avoid incoming enemies and survive for as long as possible.
- 💥 **Explosion Animations** — Enemies explode when hit.
- ❤️ **Lives System** — Manage your remaining lives and stay in the game.
- 🏆 **Score System** — Earn points by destroying enemies.
- 🎵 **Sound & Music** — Background music and gameplay sound effects.
- ✨ **Hit Effects & Screen Shake** — Extra feedback when your spaceship gets hit.
- 🕹️ **Main Menu** — Start your run from the main menu.
- 💀 **Game Over Screen** — See your final score and receive a performance comment.
- 🔄 **Restart Option** — Start another run after Game Over.
- ♾️ **Unlimited Run** — Keep playing and challenge yourself to achieve a higher score.

## 🕹️ Controls

| Action | Controls |
|---|---|
| Move Up | `W` or `↑` |
| Move Down | `S` or `↓` |
| Move Left | `A` or `←` |
| Move Right | `D` or `→` |
| Shoot | `Spacebar` or `Left Mouse Button (LMB)` |

Choose whichever movement controls feel more comfortable and aim for your best score!

## ▶️ How to Run from Source

1. Download or clone this repository.
2. Install a compatible version of [Godot Engine](https://godotengine.org/).
3. Open Godot's Project Manager.
4. Click **Import** and select the `project.godot` file inside the project folder.
5. Open the project.
6. Press **F6** to run the current scene or **F5** to run the main project scene.
